# **VACATION PLANNER**

_"a vacation from your other vacation planner-planning apps."_

## **PURPOSE**

> Put simply, this is a mobile application written primarily in Java that gives the user a simple and intuitive UI for planning vacations. The purpose is to allow the user to plan for vacations while keeping the user interface simple and functionable. The user can add, delete and share vacations, which must have a start date and an end date attached to them. In addition, "excursions" —more commonly known as activities— are able to be created for each vacation. These excursions must fall within the start and end date of the vacation and are viewable within the details page of each vacation. A vacation cannot be deleted if it has excursions under it, and a vacation must at least have a name in order to be saved.

> The app has validation for dates (both the format of them as well as that the end date is not before the start date) and the user can also optionally create notifications to be generated on their device when the day on their mobile device's calendar is aligns with the start and/or end date of their vacation. This can be set for the start date of the excursion as well.

> Lastly, you can "Share" a vacation by tapping "Share Vacation" in the vacation details drop down while inspecting a vacation to copy your vacation and its details in a text format to the clipboard.

## **HOW TO OPERATE _VACATION PLANNER_**

**_(And meet all the rubric aspects)_**

> To use **_VACATION PLANNER_**, open up the application and hit the "Start" button. From there you will be taken from the **Home screen** to the **Vacation List screen**.

> The **Vacation List screen** is where you will find all your vacations listed out and where the app displays the following details for each vacation: **vacation title**, **vacation hotel**, **vacation start date** and **vacation end date**. At first, there will be no vacations displayed as none have been created yet. To **create a vacation**, tap on the plus button in the bottom right corner of the screen to be taken to the **Vacation Details and Excursions screen**.

> Once on the **Vacation Details and Excursions screen**, this is where you will be presented with the interface to create vacations. The editable fields for a vacation are **vacation title**, **vacation hotel**, **vacation start date** and **vacation end date**. The only field needed to save a vacation is the title of the vacation. The **start and end dates are also checked** so that the format of the date matches the standard "MM/DD/YYYY" format used throughout the app. The app also **validates that the vacation start date is before the vacation end date**. You can also **choose to have the app notify you via notification when the calendar of your device matches day of your vacation start and/or end date**. You can **add as many vacations as desired** here. Once finished filling out the details of your vacation, you can tap on the ellipsis on the top right which will allow the user to **Save the Vacation**, **Delete the Vacation** or **Share the Vacation**. This is the only way the user has to save a vacation and delete a vacation. If you want to **update the vacation**, simply editing any field and then click on "Save Vacation" to save your changes. Additionally, tapping on "sharing a vacation" will populate the user's clipboard with the details of the vacation and its associated excursions in a neat format.

> Speaking of excursions, the Vacation Details page above is where the user will see **a list of created excursions that are associated with the vacation** on the screen. At first, there will be no excursions displayed as none have been created. To create an excursion for a vacation, tap on the plus button in the bottom right of the screen (once the vacation start and end dates have been set) to be taken to the **Excursion Details screen**.

> Once on the **Excursion Details screen**, you can add an excursion by filling out the fields and then hitting the ellipsis in the top right to **Save the Excursion**. The available fields are **excursion title** and **excursion date**. There is also **date validation that the date entered matches the "MM/DD/YYYY" format** and **validation that the excursion date is within the start and end date of the vacation**. Additionally, the user can check a box **to enable the app to send a notification to the user when the calendar of their mobile device reaches the date that the excursion is set on**, similarly to the notification setting for the vacation. If you want to **update the excursion**, simply edit the fields and then click **Save Excursion** in the upper right from the ellpisis drop down menu. You can also select **Delete Excursion** to delete the excursion. Lastly, the app will **not allow you to delete a vacation if there are any excursions associated under it**.
